# Lap Time Sim

A repo for the TR27 or TR28 lap time sim by VD

Language: MATLAB
Units: SI

## Progress

0. Foundations: ball drop with drag, mass-spring-damper [complete]
1. Quarter-car ride model                               [complete]
2. Fixed-mu skidpad                                     []
3. Straight-line acceleration + braking                 []
4. Weight transfer                                      []
5. Tire model                                           []
6. GGV diagram                                          []
7. Quasi-steady-state lap sim                           []
8. Validation                                           []


## Stage 0 files

- simpleDragSim.m: A simple matlab script to practice matlab plotting
- massSpringDamperSim.m: a simple MATLAB script to that plots spring-damper height

## Stage 1 files
- params.m: a script holding the parameters to be used for the whole project
- QuarterCarModel.m: a script that lets you simulate a quarter car model and graphs the results
